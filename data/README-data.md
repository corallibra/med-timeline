# 中西医对照时间轴 — 数据说明

部署、备份和发版见仓库根目录 [README.md](../README.md)。本文件只说明 `timeline.json` 的字段。

## 文件

- `timeline.json` — 主数据（`meta` + `events[]`），供非对称纵向时间轴 UI 使用。

## 年代约定

| 字段 | 含义 |
|------|------|
| `year` | 整数。公元前为负（如希波克拉底约前460 → `-460`）；公元后为正。 |
| `yearEnd` | 有明确起讫时填写结束年；单年事件为 `null`。仅知“某世纪”时，`year` 取该世纪中点，范围写入 `yearLabel` / `yearEnd`。 |
| `yearLabel` | 轴侧展示用中文标签（如 `约前1600`、`1578`、`约1522–1572`）。 |
| `side` | `west` = 西方医学（含近东、希腊罗马、伊斯兰黄金时代、欧洲科学医学）；`east` = 中国传统医学及相关考古/制度。 |
| `confidence` | `high` 年与史实较确；`medium` 年代约数或文献有争议；`low` 传说、托名或细节难证（摘要中会注明）。 |
| `archaeology` | 以出土文物/遗址为主要依据时为 `true`。 |

事件按 `year` 升序排列；西东**不必成对**，各自落在共享时间轴上。

## 主要不确定点

1. **传说与托名**：神农、伏羲九针、伊尹汤液、华佗麻沸散细节等标 `low`，不编造精确年。
2. **经典成书过程**：《黄帝内经》《神农本草经》《难经》等为长期编订，`year` 用区间中点或传统纪年，摘要说明非一人一时。
3. **考古闭库年 ≠ 文本写作年**：马王堆（前168）、张家山（前186）、老官山/天回（约前157–前141）等用墓葬下葬/封闭年；满城针具是否即针灸针仍有讨论。
4. **人痘年代**：明代人痘有 1522 文献说与隆庆年间（1567–1572）较丰富记载两说，条目用区间并标 `medium`。
5. **伊斯兰医院早期年表**：巴格达首家比马里斯坦具体年有异说，取学术常用约年并注来源域。
6. **“西方”边界**：伊斯兰医学、拜占庭、近东按用户定义归入 `west`，以便与 `east`（中医）对照，不表示文化归属简单化。
7. **截止**：主跨度至约 2000 CE（含人类基因组草图、甲肝疫苗等）；青蒿素突破取 1971 实验节点（诺奖为 2015，未单列于截止年后）。

## 来源策略

`sources` 为短引用或域名（维基时间线、国家中医药博物馆史纲、PMC/诺贝尔讲稿、考古专论等），便于核对，而非完整学术书目。宁可少记、标低置信，也不虚构精确年或假来源。

## 更新

`meta.updated` 为 ISO 日期（时区 Asia/Hong_Kong）。扩充条目后请重算 `meta.eventCount` / `westCount` / `eastCount`，并保持按年排序与 `id` 唯一。
